# Contributing

Thank you for improving the Acadify Solution Engineering Standards.

## Before You Start

Read:

- [README.md](README.md)
- [GOVERNANCE.md](GOVERNANCE.md)
- The relevant document under [standards/](standards/)

## Make a Change

1. Open an issue for a new rule or meaningful policy change.
2. Create a short-lived branch using [Branching & Git Guidelines](standards/branching-git.md).
3. Make the smallest complete documentation or tooling change.
4. Run `npm run lint`.
5. Open a pull request using the repository template.
6. Address review feedback and record meaningful decisions.

## Writing Guidance

Prefer concrete rules, actionable security guidance, consistent terminology, useful examples, and standards that can realistically be automated.

Avoid unverified compliance claims, local machine paths, credentials, secrets, and rules that exist only because they sound professional.

## Documentation Quality

Every standard should answer:

1. What is the rule?
2. Why does it exist?
3. When does it apply?
4. What is a good example?
5. How is compliance verified?
